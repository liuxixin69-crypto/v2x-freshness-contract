# 实验数据说明

生成脚本（Node ≥ 18，无第三方依赖）：

| 脚本 | 产出 |
|---|---|
| `代码/run_experiments.js` | E1–E5：明细 / 汇总 CSV、`关键数字.md` |
| `代码/gen_heatmap.js` | E6：可行域 CSV / JSON、`可视化数据校验.md` |

复现命令（在项目根目录执行）：

```
node 代码/run_experiments.js
node 代码/gen_heatmap.js
```

会覆盖本目录下对应产物。**论文与汇报中的所有数字均取自这里；改实验参数后必须重跑脚本并同步全文。** E6 的 JSON 还被 `代码/build_prototype.js` 内嵌进 v0.2 原型，改完热力图数据要顺手重建一次 HTML。

## 文件清单

| 文件 | 内容 |
|---|---|
| `实验明细_runs.csv` | 逐种子原始结果，每次独立运行一行（4800 行） |
| `实验汇总_summary.csv` | 每组 30 种子的均值/极值/比率（160 组） |
| `关键数字.md` | 脚本自动生成的论文用表格，勿手改 |
| `预警可行域_heatmap.csv` | E6 二维扫描：3 场景 × 110 格 = 330 组汇总（9900 次运行） |
| `预警可行域_heatmap.json` | 同样数据的紧凑网格格式，内嵌进 v0.2 原型 |
| `可视化数据校验.md` | E6 与 E2/E3 的 21 个交叉点逐点比对记录 |
| `README.md` | 本说明 |

CSV 为带 BOM 的 UTF-8，Excel / WPS 双击可直接打开。JSON 单元格格式为 `[safe_rate_%, miss_rate_%, margin_s×100]`，行 = 单程时延（0–1000 ms，11 档），列 = 丢包率（0–90%，10 档）。

## 明细字段（实验明细_runs.csv）

| 列 | 字段 | 单位 / 说明 |
|---|---|---|
| 1–5 | exp, scene, tag, x_name, x_value | 实验编号、场景键、条件标签、扫描维度与取值 |
| 6–10 | loss_pct, tau_ms, freq_hz, noise_m, valid_ms | 注入参数：丢包率 %、单程时延 ms、BSM 频率 Hz、位姿噪声标准差 m、BSM 有效期 ms |
| 11 | seed | 固定种子 `k*7919+13`（k=1..30） |
| 12–13 | tc_s, warn_s | 理想链路关键时刻、本次首次预警时刻（空 = 从未预警） |
| 14 | margin_s | 预警提前量 = tc − warn，无预警记 0 |
| 15–16 | missed, safe | 是否漏警（0/1）、是否满足 1.5 s 安全余量（0/1） |
| 17–18 | aoi_mean_ms, blind_rate_pct | 平均信息年龄、信息失明帧占比 |
| 19–20 | recv, sent | 成功接收 / 发出的 BSM 条数 |

## 实验矩阵

| 编号 | 目的 | 自变量 | 固定条件 |
|---|---|---|---|
| E1 | 预设对比 | 5 种链路预设 × 3 场景 | 有效期 500 ms |
| E2 | 丢包退化曲线 | 丢包 0–90%（步长 10）× 3 场景 | 时延 100 ms、10 Hz、有效期 500 ms、噪声 0.2 m |
| E3 | 时延悬崖 | 时延 0–1000 ms（步长 100）× 3 场景 | 丢包 10%、10 Hz、有效期 500 ms |
| E4 | 单因素消融 | 基线 / 仅丢包 60% / 仅时延 600 ms / 两者叠加 × 3 场景 | 其余同基线 |
| E5 | 有效期敏感性 | 有效期 100/300/500/700/1000 ms × 时延 0–1300 ms | FCW、丢包 10%、10 Hz |
| **E6** | **二维预警可行域** | **丢包 0–90% × 时延 0–1000 ms（110 格）× 3 场景** | **10 Hz、有效期 500 ms、噪声 0.2 m、同批 30 种子** |

E6 与 E2/E3 刻意共用同一 BASE 与同一批种子，因此：
- 固定 `loss=10%` 的时延列 = E3_tau_sweep（11 点）
- 固定 `tau=100 ms` 的丢包行 = E2_loss_sweep（10 点）

共 **21/21 个交叉点完全一致**，见 `可视化数据校验.md`。这条校验是「热力图不是另画一张装饰图」的证明，答辩被问「数据哪来的」时直接翻它。

## 固定参数

`DT=0.05 s`、`MAXT=10 s`、车长 `LEN=4.5 m`、安全余量 `SAFE=1.5 s`、
TTC 预警阈值 `3.5 s`、紧急阈值 `1.75 s`、每点 30 个固定种子。

三个场景（与交互原型一致）：

| 场景 | 主车 | 远车初速 | 初始间距 | 减速时刻 | 减速度 |
|---|---|---|---|---|---|
| FCW | 60 km/h 匀速 | 40 km/h | 55 m | 1.0 s | −6 m/s² |
| EBW | 60 km/h 匀速 | 50 km/h | 60 m | 2.5 s | −9 m/s² |
| ICW（等效一维） | 65 km/h 匀速 | 40 km/h | 55 m | 2.0 s | −7 m/s² |

理想链路关键时刻 tc（从仿真起点到真实间距归零）：FCW 4.30 s、EBW 6.05 s、ICW 4.50 s。
预警提前量 = tc − 首次预警时刻；理想链路下 FCW 约 2.40 s。

## 口径提醒

- 「漏警」= 全程未触发预警，或预警时刻已晚于理想链路关键时刻；「来得及」= 未漏警且提前量 ≥ 1.5 s。
- 「信息失明」= 当前帧的 BSM 信息年龄 AoI 超过有效期，本帧不参与判定。这是模型中让时延产生决定性影响的关键机制。
- 阈值、有效期、场景参数均为**课程级简化设定**，不是标准规定值；ICW 为等效一维近似。结论只能表述为「受控退化下的趋势」。
- 原型视图 ③ 的「按当前参数重算」使用同一内核与 30 种子，但按页面当前有效期 / 频率 / 噪声计算，属现场演示口径，页面会标注；**写论文请引用本目录 CSV，不要用重算后的数字**。
- 外部对照数字（3GPP TS 22.185、CooperScene 等）来自 `03` 文件的检索摘要，**尚未回原文核验**，不写入本目录数据，仅在论文讨论章节标注引用。
