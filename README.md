## 核心结论（2026-11-05）

| 实验 | 结果 |
|---|---|
| E1 预设（FCW） | 理想 2.40 s / 命中 100%；3GPP 100 ms 合规 2.38 s / 100%；严重退化 0 s / 漏警 100% |
| E2 丢包扫描 | 固定时延 100 ms，丢包 0→90%：提前量 2.40→1.36 s，漏警 0→17%，命中率 100→57% |
| E3 时延扫描 | 500→600 ms：漏警率 0→100%，失明率 73→100%（时延悬崖） |
| E4 消融 | 仅丢包 60% 几乎无影响（2.29 s）；仅时延 600 ms 即 100% 漏警 → 时延主导 |
| E5 有效期敏感性 | 有效期 100/300/500/700/1000 ms → 观测断崖 200/400/600/800/1100 ms（整体平移） |
| E6 可行域 | 3 场景 × 110 格 × 30 种子 = **9900 次运行**；**21/21 交叉点**与 E2/E3 完全一致；90% 丢包 + 100 ms 时来得及率仅 **56.7%**、漏警 16.7% |
| **E7 解析判据** | τ>V 的 **15/15 格点全部 100% 失明且 100% 漏警**；占空比模型预测失明率 MAE **4.44 pp**；失明 97.6% 仍可能不漏警 |
| **E7 契约反解** | 保守界 p ≤ 47.3%，窗口感知紧界 p ≤ 75.4%（δ=0.05），后者与 E6 实测过渡区同量级 |

假设判定：H1 成立、H2 成立、**H3 部分成立**（余量厚薄有场景差异，但断崖位置三场景同为 600 ms）。

## ⚠️ 口径修正（本轮重点）

初稿把临界时延写作「BSM 有效期 + 一个发送周期（100 ms）」，**已判定不准确并修正 11 处**（期末论文、PPT 生成脚本、展示脚本、README、08 文件）：

- 真正的硬边界是 **τ ≤ V**（V 为 BSM 有效期）：包在 `t_send+τ` 到达，到达瞬间 AoI ≡ τ，故 τ>V 时消息落地即过期、全程失明，与丢包率无关。
- 多出的 100 ms 是 **100 ms 扫描步长**与门控边界（严格大于 + 浮点/单帧采样）的离散表现；`τ=V` 行为不稳定，不作为结论依据，工程上需留 ≥1 个采样步长裕量。
- E5 五组有效期下断崖整体平移，验证的是 τ 与 V 的相对关系，而非固定常数。
- 推导、验证与修正说明见 `数据/E7_结论.md` 与论文 5.9 节。
